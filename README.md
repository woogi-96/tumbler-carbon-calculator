# 내 텀블러는 친환경일까?

텀블러를 몇 번 더 써야 일회용컵보다 탄소를 줄이는지 계산하고, 매일의 사용과 내부 사진 상태를 기록하는 웹앱입니다.

- `index.html`: 웹페이지. 상위 프로젝트의 `run_pipeline.py`가 생성합니다.
- `manifest.webmanifest`, `sw.js`, `*.png`: 홈 화면 앱 설정, 오프라인 캐시, 아이콘. `sw.js`도 `run_pipeline.py`가 생성합니다.
- 서버 함수가 없습니다. 기록, 사진, 진단 결과는 방문자 브라우저에만 저장되고 어디에도 전송되지 않습니다.
- 사진 진단은 브라우저 안에서 색상만 측정하는 무료 방식입니다.

## 아이폰에서 앱으로 쓰기

Safari로 사이트를 열고 공유 버튼에서 "홈 화면에 추가"를 고릅니다. 홈 화면 아이콘으로 열면 주소창 없이 열리고, 신호가 없어도 열립니다.

환경변수가 필요 없습니다. 이 저장소에는 API 키나 비밀번호를 넣지 마세요.
