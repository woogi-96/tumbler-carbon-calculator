# 내 텀블러는 친환경일까?

텀블러의 탄소 손익분기점을 계산하고, 내부 사진으로 상태를 추정하는 연구 프로토타입입니다.

- `index.html`: 웹페이지. 상위 프로젝트의 `run_pipeline.py`가 생성합니다.
- 사진 진단은 브라우저 안에서 색상만 측정하는 무료 방식입니다. 사진은 외부로 전송되지 않고 요금도 들지 않습니다.
- `api/data.py`: 닉네임 계정, 사용 횟수 저장, 연구자용 CSV입니다. 사진을 받는 입력은 없습니다.

## 환경변수 (Vercel 프로젝트 설정)

| 이름 | 설명 |
|---|---|
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Upstash Redis를 프로젝트에 연결하면 자동으로 등록됩니다. |
| `ADMIN_PASSWORD` | CSV를 받을 때 쓰는 연구자 비밀번호입니다. |

## 연구자 관리 화면

`/api/data?op=admin`을 열고 `ADMIN_PASSWORD`로 로그인합니다. 모집 상태(닫힘, 참여 코드, 열림), 가입 상한, 동의 안내, PIN 초기화를 다룹니다. 처음 상태는 닫힘이며, 열림으로 바꾸려면 동의 안내를 채워야 합니다.

## CSV 받기

브라우저에서 아래 주소를 열고 사용자 이름은 아무 값, 비밀번호는 `ADMIN_PASSWORD`를 입력합니다.

- 날짜별: `/api/data?op=export` (닉네임, 날짜, 사용 횟수, 나중에 전송된 횟수)
- 사람별 합계: `/api/data?op=export&view=total`

API 키를 이 저장소의 파일에 넣지 마세요.

## 게임: 멍뭉이 털을 찾아라

- `Game.html`: 파일 하나로 된 브라우저 게임입니다. Vercel에 배포되면 `/Game`(또는 `/Game.html`) 주소로 열립니다.
- 테스트: `node --test` (Playwright와 Chromium이 필요합니다). 테스트는 `vercel.json`의 보안 헤더(CSP)를 그대로 붙여 로컬에서 페이지를 띄우고, 1단계 진행, 점수(+5/-1), 통과·실패, 10단계 도구, 다음 날 진행, 엔딩, 모바일 터치를 확인합니다.
