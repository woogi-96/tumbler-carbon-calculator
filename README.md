# 내 텀블러는 친환경일까?

텀블러의 탄소 손익분기점을 계산하고, 내부 사진으로 상태를 진단하는 연구 프로토타입입니다.

- `index.html`: 웹페이지. 상위 프로젝트의 `run_pipeline.py`가 생성합니다.
- `api/analyze.py`: 사진 진단 중계 함수. API 키는 서버 환경변수에만 둡니다.

## 환경변수 (Vercel 프로젝트 설정)

| 이름 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 예 | 없으면 사진 분석만 꺼지고 나머지는 동작합니다. |
| `RATE_LIMIT_PER_IP` | 아니요 | IP별 허용 횟수 (기본 5회) |
| `RATE_LIMIT_WINDOW_SECONDS` | 아니요 | 위 횟수를 세는 시간 (기본 600초) |
| `DAILY_LIMIT` | 아니요 | 서버 인스턴스별 하루 허용 횟수 (기본 300회) |
| `ALLOWED_HOSTS` | 아니요 | 추가로 허용할 도메인 (쉼표로 구분) |

횟수 제한은 서버 인스턴스별로 따로 세므로 정확한 상한이 아닙니다. 실제 비용 상한은 Anthropic 콘솔의 지출 한도로 설정합니다.

API 키를 이 저장소의 파일에 넣지 마세요.
